🥔 Ultimate Allu Racer

Ultimate Allu Racer is an exciting 2D hill climbing racing game built with HTML5, CSS3, and Vanilla JavaScript. Race across unique environments, collect coins, unlock powerful vehicles, and upgrade your ride to conquer increasingly difficult tracks.

Explore a variety of maps including Countryside, Desert, Snow, Jungle, Volcano, City, Moon, Candy Land, and more. Each map features its own terrain, atmosphere, and challenges. Unlock new maps using coins, with each new location becoming more expensive than the last.

Customize your vehicle with upgrades such as Engine, Suspension, Fuel Tank, Tires, Nitro, Turbo, and Armor. Every upgrade improves your vehicle's performance and helps you travel farther.

The game includes responsive controls for both mobile and desktop, smooth physics, realistic vehicle movement, checkpoints, collectible fuel cans, coin rewards, achievements, daily rewards, lucky spin, redeem codes, and automatic game saving using LocalStorage.

Enjoy animated environments with moving clouds, trees, rocks, bushes, weather effects, dynamic lighting, particle effects, and immersive background music and sound effects for a richer gameplay experience.
